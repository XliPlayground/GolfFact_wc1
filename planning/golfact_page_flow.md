# Golfact 页面流程图

> 角色：用户（会员/散客）、教练、管理员
> 设计原则：简约绿色主题，底部 Tab 导航，后台左侧导航

---

## 1. 角色与入口

```
微信小程序
├── 用户端（默认入口）
│   └── 微信一键登录 → 自动注册用户
├── 教练端
│   └── 账号密码登录（由后台开通）
└── 管理后台
    └── 账号密码登录（由超级管理员开通）
```

---

## 2. 前台用户端

### Tab 结构

```
┌──────────────────────────────────────────────┐
│  首页  |  打球预约  |  下场记分  |  会员排名  |  设置  │
└──────────────────────────────────────────────┘
```

> 说明：「小店吧」「教练展示」从底部 Tab 移除，改为首页内的快捷入口卡片，减少一级导航复杂度。

### 页面清单

#### 首页 `pages/index/index`
- 场地名称 / Logo（读 settings.site）
- 门店公告 / 轮播图
- 快捷入口网格：
  - 立即预约
  - 我的预约
  - 下场活动
  - 会员赛
  - 小店吧
  - 教练展示
- 秋の认证：一杆进洞数、鹰数、鸟数、Par数、一只鸡数
- 最近 10 场比赛总杆数折线图
- 最近活动卡片
- 下场活动/会员赛：会员查看活动详情，报名后等待老板确认；满员、报名截止或活动取消后不可报名

#### 打球预约 `pages/booking/index`
- 选择预约类型：自助打位 / 培训
- 选择日期
- 选择时段（酒店式先选开始、再选结束；30 分钟一段，每次至少选 2 段）
- 时段必须连续，不允许间隔选择；已占用时段用灰色块区分，不在格子里写说明文字
- 选择打位（2 个）
- 选择教练（仅培训，且只显示老板后台已关联教练）
- 填写需求：
  - 准备球 / 准备杆 / 准备水 / 准备茶点
  - 是否准备烟灰缸
  - 到访人数
- 确认预约（显示折后价格、扣除时长）
- 校验：每日累计预约不超过后台限制

#### 预约详情 `pages/booking/detail`
- 预约信息：日期、时段、打位、预约类型、教练、到访人数、服务需求、烟灰缸
- 结算信息：扣除时长、结算状态、48 小时确认截止、爽约追加扣时
- 取消预约按钮：取消后退回已扣时长并释放时段
- 自助预约显示门禁密码（预约当天显示）
- 导航到店

#### 小店吧 `pages/shop/index`
- 分类 Tab：水 / 点心 / 衣服 / 装备
- 商品列表
- 商品详情（图片、价格、描述、库存）
- 提示：到店线下支付

#### 教练 `pages/coach/index`
- 教练列表卡片
- 教练详情（照片、简介、专长、可预约入口）

#### 设置 `pages/mine/index`（原「我的」）
- 头像 / 昵称 / 会员等级
- 剩余小时数及有效期概览
- 功能入口：
  - 我的预约
  - 我的积分
  - 爽约记录
  - 充值记录 / 到期日
  - 下场活动报名
  - 会员赛报名
  - 联系门店
  - 关于我们

#### 我的预约 `pages/mine/appointments`
- 待使用 / 已完成 / 已取消 Tab
- 列表展示

#### 充值记录 `pages/mine/recharges`
- 每次充时记录：小时数、到期日、充值时间
- 有效期状态：有效 / 即将到期 / 已过期

#### 下场记分 `pages/scorecard/index`
- 历史记录分为两个书签：
  - 自己记录：会员可新建、编辑、修改、删除
  - 秋の认证：老板/活动录入产生，只能查看不可修改
- 选择场地
- 选择日期
- 逐洞记录：打击杆数、推球杆数、罚杆均用 0-10 滚轮选择
- 每次选择后自动保存草稿，避免退出或断网丢数据
- 保存记分卡时选择球场名称；可用 GPS 记录当前位置，未来接地图服务反查球场名
- 提交 / 保存草稿

#### 会员排名 `pages/ranking/index`
- Tab：近 5 场最佳 / 近 5 场平均 / 历史最好成绩
- 秋の认证榜：第一行鹰王、鸟王；第二行一杆进洞王、Par王、一只鸡王
- 榜单列表，显示本人排名与成绩

### 核心页面

#### 会员管理 `pages/admin/users`
- 会员列表：姓名、手机号、剩余时长、已关联教练数
- 新建/编辑会员：姓名、手机号、会员等级、初始时长、状态
- 状态管理：正常 / 待处理 pending / 删除 deleted（软删除，历史记录保留）
- 会员详情：剩余时长、累计充值、爽约次数
- 手动调整时长：支持正数补时、负数扣时，必须填写原因并生成时长记录
- 关联教练：勾选可服务该会员的教练，用户端预约教练时只显示已关联教练
- 最近记录：展示该会员最近预约和最近时长记录

#### 活动管理 `pages/admin/activities`
- 老板发布活动，字段包括球场/场地、日期时间、行程、预计人数、餐食、费用、报名起止时间、活动说明
- 活动可关联球场基础库，成绩录入时自动带出该球场每洞标准杆
- 活动列表分为募集中 / 完成两个标签管理
- 会员在小程序内查看活动详情并报名，报名状态先进入待确认
- 老板审核报名：同意 / 拒绝
- 达到人数上限或报名截止后，老板可确认成团
- 活动后老板标记会员履约 / 爽约，并进入活动成绩录入
- 活动成绩保存为秋の认证记录，会员端只读查看

#### 球场管理 `pages/admin/courses`
- 上云后优先补全北京、天津、河北营业球场基础库
- 球场需支持多分场/九洞区，例如 A 场、B 场、C 场
- 18 洞标准杆按组合保存，例如 A+B、B+C、A+C，而不是只按球场保存一套
- 活动发布和下场记分都从球场组合中选择，并带出每洞标准杆

#### 球场管理 `pages/admin/courses`
- 维护全国球场基础库，结构支持逐步导入 335 座营业球场
- 字段包括名称、省份、城市、地址、经纬度、洞数、18洞标准杆、场地特点、数据来源
- 每洞地图先保留 `holeMaps.mapUrl` 占位，避免小程序包体过大；后续改用云存储 URL

#### 品牌设置 `pages/admin/settings/site`
- 场地名称
- Logo 上传
- 门店招牌上传
- 联系电话
- 地址
- 首页公告

#### 充值管理 `pages/admin/recharges/list`
- 所有用户充值记录列表
- 筛选：用户、日期范围、到期状态、状态
- 给用户新增充值：输入小时数、到期日（金额字段隐藏/可选）
- 充值后自动计入用户剩余小时数
- 查看用户有效期汇总

#### 充时卡/权益码 `pages/admin/vouchers/list`
- 三页管理：在效期 / 过期 / 已使用
- 卡片列表：卡号、批次、类型、小时数、充值后有效天数、卡本身有效期、状态、兑换用户
- 模板管理：销售卡、体验卡、福利加油包、自定义卡
- 批量生成实体卡：生成卡号、长兑换码 token、二维码路径
- 扫码激活：老板扫实体卡后填写/预填模板信息，点击确认即可激活
- 连号批量激活：输入起始卡号 + 数量 + 模板，一次激活连续递增卡号（当前 mock 已实现）
- 编辑/延期：未使用卡可编辑小时数、充值后有效天数、卡本身有效期；过期卡可通过延期回到在效期
- 状态管理：active / inactive / pending / used / deleted；pending 暂缓兑换，deleted 软删除
- 兑换记录：查看兑换时间、兑换用户、生成的充值记录

#### 营业时段 `pages/admin/settings/business`
- 默认营业时间
- 时段粒度固定 30 分钟
- 特殊日期调整

#### 预约规则 `pages/admin/settings/booking`
- 每次最少预约段数：2 段（1 小时）
- 每日最多预约小时数：后台可配置
- 是否允许跨时段连续预约
- 结算确认窗口：默认 48 小时
- 爽约倍率：默认 1.5 倍

#### 预约管理 `pages/admin/appointments`
- 状态页签：待确认 / 已完成 / 取消或爽约 / 全部
- 筛选：会员、日期
- 待确认预约可标记完成、取消、爽约
- 爽约按后台倍率追加扣时；取消释放时段并退回已扣时长

#### 爽约规则 `pages/admin/no_show/rules`
- 爽约时间阈值（N 小时）
- 每个缴费周期允许次数
- 默认惩罚模式：按实际抵扣 / 按比例抵扣
- 默认惩罚值
- 用户单独覆盖列表

#### 时段管理 `pages/admin/time_slots/list`
- 日历视图
- 批量生成时段
- 设置每个时段：类型（教学/自助）、基础价格、折扣、是否开放、关联教练

#### 门禁密码 `pages/admin/access_codes/list`
- 当前密码显示
- 修改密码
- 生效时间
- 历史记录
- 门锁联动配置（预留）

#### 教练账单 `pages/admin/coach_bills/list`
- 教练筛选
- 周期筛选
- 账单状态筛选
- 标记已拨付

## 5. 关键流程

### 5.1 预约流程

```
用户选择类型（自助/培训）
    ↓
选择日期 → 查询开放时段（30 分钟一段）
    ↓
选择时段 + 打位（至少连续 2 段 = 1 小时）
    ↓
[培训] 选择教练
    ↓
填写需求（球/杆/水/茶点/烟灰缸/到访人数）
    ↓
确认扣除时长
    ↓
提交预约
    ↓
系统校验：
    - 时段冲突
    - 所选时段 ≥ 2 段
    - 当日累计预约小时数 ≤ maxDailyBookingHours
    - 剩余有效时长充足（优先扣除快到期的小时数）
    - 爽约限制
    ↓
预约成功 → 从 recharge_records 扣除时长 → 生成预约记录
    ↓
[自助] 预约当天显示门禁密码
```

### 5.2 取消与爽约判定流程

```
预约创建后
    ↓
基础预约时长进入 pending / 已冻结状态
    ↓
预约结束
    ↓
进入 48 小时老板确认窗口
    ├── 老板点完成 → 正常结算，状态 = completed
    ├── 老板点爽约 → 按后台爽约倍率结算，默认 1.5 倍，状态 = no_show
    └── 48 小时未处理 → 无异议自动完成，状态 = completed
```

用户主动取消：

```
用户点击取消预约
    ↓
系统计算：距离开场还有多久
    ↓
≤ N 小时？
    ├── 是 → 标记为临时爽约
    │         ↓
    │         当前周期爽约次数 +1
    │         ↓
    │         是否超过允许次数？
    │           ├── 是 → 执行惩罚（按实际/比例抵扣时长）
    │           └── 否 → 仅记录，不额外惩罚
    │         ↓
    │         取消成功
    └── 否 → 正常取消，释放时段，退还时长
```

### 5.3 充时卡 / 权益码流程

```
方式 A：老板直接充时
老板选择用户 → 输入小时数和到期日 → 生成 recharge_records → 用户可用时长增加

方式 B：固定套餐卡 / 体验卡 / 福利加油包
老板选择模板 → 批量生成卡片 → 实体卡印刷/贴码 → 客户扫码 → 长兑换码自动兑换成功后卡片 used

方式 C：预制空卡后激活
先批量生成 inactive 空卡 → 老板销售/发放时扫卡 → 选择模板（销售卡/体验卡/福利卡）→ 信息预填 → 点击激活 → 客户扫码兑换

方式 D：连号批量激活
老板输入起始卡号 + 数量（如 10 张）→ 选择模板 → 系统按卡号递增激活一段卡 → 适合一次性销售/发放多张实体卡
```

兑换校验规则：
- 二维码只包含 token；小时数、有效期、限制规则以云端记录为准。
- active 且未过期且限制规则通过时才可兑换。
- 体验卡可设置生命周期仅一次或仅新用户一次。
- 福利加油包可设置不限制、每人一次、周期一次或指定会员等级。
- 兑换成功后创建 recharge_records，并将卡状态改为 used，不能再次兑换。

### 5.4 自助预约与门禁密码流程

```
用户完成自助预约
    ↓
系统读取当前生效 access_codes.code
    ↓
预约状态为 booked
    ↓
预约当天（或开始前 X 小时）
    ↓
预约详情页显示门禁密码
    ↓
用户到店输入密码进入
    ↓
管理员可在后台手动更换密码
```

### 5.5 教练账单流程

```
教练进入「我的账单」
    ↓
选择周期（周/月/自定义）
    ↓
系统汇总该周期内已完成且未生成账单的培训课程
    ↓
生成账单：课时数 × 课时单价 = 总金额
    ↓
状态 = 待讨薪
    ↓
教练提交对账（可线下找老板核对）
    ↓
老板确认后，管理员后台标记 = 已拨付
    ↓
教练端账单状态同步更新
```

### 5.6 下场记分卡流程

```
用户下场打球
    ↓
方式 A：实时记录（每洞打完即时录入）
方式 B：事后补填（整轮结束后一次性录入）
    ↓
选择场地 + 日期
    ↓
逐洞用滚轮选择：打击杆数、推球杆数、罚杆（0-10）
    ↓
每次选择自动写入草稿
    ↓
计算总杆数 / 总推杆数
    ↓
选择球场名称并提交记分卡
    ↓
[会员赛] 成绩进入待审核状态
    ↓
管理员审核通过后计入积分排名
```

### 5.7 积分排名流程

```
比赛积分：
会员赛成绩审核通过 → 按名次/杆数换算积分 → 写入 points_records → 更新用户比赛积分排名

训练积分：
自助/培训预约完成 → 按训练时长换算积分 → 写入 points_records → 更新用户训练时间积分排名
```
